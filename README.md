# Love Letter Generator

![perfect-love-card (4)](https://github.com/user-attachments/assets/529c3784-662e-49f4-9175-29b6059aea8a)


This project is a web-based AI-powered love letter generator that uses image input along with user and lover details to create a personalized love letter. The generated letter is styled as a beautiful card with an image, which can be downloaded.

## Technologies Used
- **HTML, CSS, JavaScript** - For the frontend UI
- **Python, Flask** - Backend framework
- **DeepSeek R1 AI Model** - AI-powered content generation
- **OpenRouter API** - Enhanced AI processing

## Features
- User inputs their name, lover's name, and other details.
- Allows image input to personalize the experience.
- Uses AI to generate a heartfelt love letter.
- Formats the letter as a downloadable love card with an image.
- Fully web-based and easy to use.

## Installation & Setup
1. Clone this repository:
   ```sh
   git clone https://github.com/pettahai/love-letter-generator.git
   ```
2. Navigate to the project folder:
   ```sh
   cd love-letter-generator
   ```
3. Install dependencies:
   ```sh
   pip install -r requirements.txt
   ```
4. Run the Flask server:
   ```sh
   python app.py
   ```
5. Open your browser and go to `http://localhost:5000` to use the generator.
